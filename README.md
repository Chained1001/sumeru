# sumeru

人类作家的灵感素材库：素材分十一个类型收进结构化库（故事零件、写作方法、作品案例、现实避坑四个大类），可借助宿主联网调研全球资料，写作前按类型检索取用。给网文作者自己用，卡片与交互保持中文。

状态：实验

## 它是什么

**把它想成一个作家脑中的日常积累，被挪到了纸面上。**

写作者真正靠的不是临时搜来的资料，是这些年一点点攒下的东西：一段记得住的桥段、一句让你停下来的台词、一个让你觉得「这人真立体」的角色、一条踩过才知道的坑。它们平时散在记忆里，用的时候凭联想捞；捞不到就没了。

须弥就是给这层积累做外置存储，并让它可检索。这个定位直接决定了四件事：

**一、收的门槛很低。** 你不用先想清楚它归哪类——说一句「这个收一下」就够了，分类是系统的活（不知道就说「帮我归」）。

**二、存的是能搬走的结构，不是原文。** 看到别人一个好人设，该记下来的是「他的执念伪装成玩笑，可以搬给一个想活却总在送死的配角」——而不是把那一段抄一遍。抄下来你只能照搬，提炼出来你才能**有机融合、改编进自己的书**。这也是为什么卡上要写「为什么管用」，作品切片还要提炼「可迁移点」，以及为什么摘录有字数上限。

**三、按「我要写什么」去查，不是按「它存在哪」去翻。** 分类（四个大类、十一个类型）只是为了好找，不是限制。所以一条料可以来自小说、动漫、现实新闻，同一个角色可以跨类型各有一张卡，并用「关联卡」互指。

**四、记忆会忘、会旧、会变形。** 所以有时效状态与周期性复审，所以记「证实／单源／线索／存疑」和原始出处——记错了得能回溯。

**边界：收的是「我记得的」，不是「我写的」。** 只服务一本书的东西不收（比如第几章埋了什么伏笔这类台账），那是写书项目的件；但你从废稿里提炼出的教训要收——**废稿不收，废稿教会你的东西收。**

## 安装

```bash
npx skills add Chained1001/sumeru
```

写库需要 Node.js 24 及以上，以及宿主读取技能文件、执行命令和读写目标目录的能力。开发仓库的环境要求见 `AGENTS.md`。

安装后确认：触发 material-vault，按第一问选「故事零件」、第二问选「人物设定」，给一段路飞式角色描述，应先见两问、后产出落对目录的人设卡与 INDEX.md。

## 宿主兼容与联网取材

兼容性按当前会话具备的能力判断：

| 当前能力 | 可用范围 |
|---|---|
| 能读技能、执行 Node、读写目标目录 | 采集入库、检索、卡管理与库维护 |
| 上述能力加联网搜索或浏览器 | 调研取材、抓链接正文后入库 |
| 有子代理 | 按任务书分派采集与调研；无子代理时由主线程执行同一任务书 |
| 能读图或转写音频 | 处理对应素材；没有时请用户提供文字 |

宿主的技能功能入口：[Codex](https://developers.openai.com/codex/skills)、[Claude Code](https://code.claude.com/docs/en/skills)、[Cursor](https://cursor.com/docs/skills)。本轮只在 Codex 会话中执行过实际操作，并检查静态契约；其他宿主需在各自会话中实测。支持技能格式不等于具备当前任务所需的全部工具权限。

主线程能联网、子代理不能时，由主线程取材后交回采集，不反复向无网子代理派联网任务。宿主无法执行 Node 或写文件时，只能给整理预览，不能声称已经入库。

联网优先使用宿主原生搜索、正文抓取或浏览器。已安装且可用的 [Agent-Reach](https://github.com/Panniantong/Agent-Reach) 可作为可选工具渠道；它不是 Sumeru 内置检索引擎，也不是安装前置条件。技能不会自动安装、登录或配置该工具。

取材默认面向全球，用户指定地域时优先遵从；来源语言与主体应可追溯，可信度依据出处与独立证据判断。卡片格式与两问交互保持不变。执行规则见 `skills/material-vault/references/宿主能力适配.md` 与 `skills/material-vault/references/权威源分级.md`。

当前验证范围是 Codex 会话及仓库的静态契约检查；Claude Code、Cursor、Gemini CLI 等其他宿主尚未实机验证。能识别技能格式或满足上述能力条件，不等于已经验证端到端可用。

## 五分钟上手

装上之后，你对自己的 AI 助手说话就行，不用敲命令。入口只有两问：这算四个大类里的哪一大类（故事零件、写作方法、作品案例、现实避坑），再挑该大类下的类型（共十一个）。下面五句话各试一遍，每句后面是试对了该看到的东西。

1. 收一条素材：「这个开局点子你帮我收一下：主角重生回高考前三天，发现全班同学都记得上一次的人生。」
   你该看到什么：先问你收进哪个大类，再给该大类的类型菜单让你挑；然后产出一张卡落到 `素材库/故事零件/开书点子/`，并更新 `素材库/INDEX.md`。**这一类型的卡默认标「私有：是」**，`pack` 生成引用包时会强制排除它。

2. 只有主题、没有素材：「帮我调研一下明末党争，我想写个穿到东林党身上的。」
   你该看到什么：先问清收进哪一个类型，再联网取材；回来的卡上带来源与日期，调研过程记录写在 `辅助内容/临时文件/` 下，整篇长文不进库。

3. 要写东西、先找参考：「我要写个疯批反派，库里有能用的吗？」
   你该看到什么：按类型去库里检索，每条给要点、摘录或事实要点、卡路径，只在对话里给，不往库里写新卡。

4. 改一张已有的卡：「第 1 句收的那张点子卡，要点写歪了，帮我改一下。」
   你该看到什么：先在 `素材库/INDEX.md` 里按卡名或要点找到那张卡，改的是那张卡本身；找不到会停下来问你要路径，不猜也不覆盖。

5. 看看库况：「库里现在有多少卡？哪一类太薄？」
   你该看到什么：总卡数、四个大类各多少、各类型多少、最近收的卡、待补处数、待复审张数，以及偏薄的类型。

如果它没按预期走——比如不问类型就直接建卡——直接说「按 SKILL.md 的两问来」，它会回到入口重问。

两个最容易误会的点：

- **`demo-vault/` 是别人的库**，随技能分发，只作学习用。不要往里加东西：它是分发内容，下次更新会被覆盖。你说「就存这儿」时，它也会另建一个真库，不往示范库里写。
- **素材库默认建在当前目录的 `素材库/`**。找不到库时它会先问你是新建还是指向已有的，不会自动建；想放别处，直接告诉它路径。

私有标记控制引用包出口，不会加密素材，也不控制宿主模型读取、聊天记录、云同步或用户自行复制文件。示范库不收私有卡；使用外部宿主时，数据处理方式由该宿主决定。

## 技能列表

| 技能 | 用途 | 扩展键 |
|---|---|---|
| material-vault | 灵感素材库：入口两问定类型（四个大类、十一个类型、细分开放），素材在手走采集，只有主题按宿主能力联网调研（全球默认、用户地域优先、权威源分级取信、来源等级四档含存疑），写作前按类型路由检索；无子代理时主线程执行同一任务书；原型基底、节奏样例、伏笔清单整存，组件卡可拆并联；事实与推断分层标注 | 无 |

扩展键只填实际用到的，没有就写「无」，多个用逗号分隔。可填哪些键见 `docs/规范/01-技能写法.md` 的 frontmatter 表。表与 `skills/` 目录的一致性由 `npm run validate` 检查。
