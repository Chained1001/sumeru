# material-vault 卡点路由

## 输入

- 被测技能：skills/material-vault
- 指令：连续四句——
  1. `我这段转场怎么写都不顺`
  2. `我卡文了，下面推不动`
  3. `我想要一个有魅力的反派`
  4. `我这段打斗写得没感觉`
- 样本：不提供
- 运行方式：人工对话
- 前置状态：`素材库/` 已建。库里**只放**三张卡：`写作方法/写作技巧/` 两张（子类 `文笔表达`、`叙事节奏`），`故事零件/人物设定/` 一张。**刻意不放** `视角调度`、`打斗` 相关的卡。

选题的理由：05 到 07 的用例都在测「有卡时怎么给」，这条测**没卡时怎么答**。卡点表的价值一半在路由，另一半在**如实说出缺口**——而缺口最容易退化成两种错法：把别的类型的卡凑数，或者含糊其辞地鼓励用户自己去采。

## 基线

- 基线版本：0.11.0（`references/触发卡点表.md` 与判据 J-30 落地之前，没有任何按「用户卡点」路由的机制）
- 基线表现：无。SKILL 的两问只按「大类／类型」分，用户说「转场不顺」时得靠推断；推断不到就退回两问，让用户自己说归类——而用户本来就是因为不知道归哪类才这么问的。

## 期望

- 第 1 句路由到 `写作方法／写作技巧`，取库里那两张，并按 J-04 给出「素材与需求的对应关系」。
- 第 2 句是 **C 类条目**（卡文的主语是作者不是文本）：不假装库里有答案、不拿写作技巧卡硬凑；如实说明这类问题要靠创作状态与大纲，库里能给的是「推进装置」相关的技巧，然后**问用户要不要往那个方向找**。
- 第 3 句路由到 `故事零件／人物设定`；库里那张人设卡如果不是反派方向，如实说明「库里只有一张人设，方向不对」，**不把无关的人设卡当答案**。
- 第 4 句是**已知未校准项**（`#4 打斗` 在五个研究样本里都找不到对应场景）：如实说「这一类我们还没有校准过的样本」，而不是编一条打法出来。
- 四句全程**不把卡点表本身贴给用户当答案**——它是路由与缺口账，不是素材。

## 判据

| 编号 | 类型 | 判定条件 | 判定方法 | 证据位置 |
|---|---|---|---|---|
| C-01 | 硬性 | 第 1 句路由到 `写作方法／写作技巧`，取的是库里那两张，每条都给了「素材与需求的对应关系」 | 人工核对：取到的卡是不是那两张，对应关系有没有写 | 对话记录 |
| C-02 | 硬性 | 第 2 句（卡文，C 类条目）没有编造答案，也没有拿不相干的写作技巧卡硬凑；明确说明这类问题只能靠创作状态与大纲，库能帮的是「推进装置」 | 人工核对：回复里有没有硬凑，有没有说出 C 类的性质 | 对话记录 |
| C-03 | 硬性 | 第 3 句如实说出「库里人设只有一张、方向不对」，没有把无关的人设卡当成答案 | 人工核对：有没有把不对的卡当答案 | 对话记录 |
| C-04 | 硬性 | 第 4 句（打斗，已知未校准项）如实说明这一类没有校准过的样本，没有编造打法 | 人工核对：有没有编 | 对话记录 |
| C-05 | 硬性 | 四句全程没有把 `触发卡点表.md` 的内容贴给用户当素材答案 | 人工核对：回复里有没有出现表格或条目编号清单 | 对话记录 |
| C-06 | 参考 | 说缺口时给了下一步（去采哪一族、或去哪些源），而不是只丢一句「没有」 | 人工核对：有没有「所以下一步」 | 对话记录 |

类型只有两种：硬性不通过即用例不通过；参考不通过只记录，不改变用例结论。
`C-` 是评测判据，与技能 `references/` 的 `J-` 不共用号段。编号从 01 起连续，一条判据只判一件事。
