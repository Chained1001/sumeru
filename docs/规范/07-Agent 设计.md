# 07 Agent 设计

本文件规定技能内子代理的设计。模板见 `templates/skill/agent.md`，位置见框架树第一节。

## 位置与数量

- 子代理放在 `skills/<技能名>/agents/`，每个子代理一个文件。
- 文件名为角色的中文短名，如 `联网检索.md`。
- 只有确实需要独立上下文、独立工具权限或并行执行时，才设子代理。能在流程内完成的步骤，不设子代理。

## 文件内容

每个子代理文件固定包含以下小节，顺序不变：

1. 角色：一句话，写明负责什么。不写身份句。
2. 输入：字段、类型、是否必需、缺失时的处理。
3. 输出：结构化字段，顺序固定。
4. 可用工具：白名单。未列出的工具一律不得调用。
5. 调用方：哪个流程的哪一步调用它。
6. 步骤：祈使句，每步一个动作。
7. 停止条件。
8. 失败回退：失败时返回哪些字段，不得伪造结果。

## 调用与校验

- 只有流程可以调用子代理。子代理不调用其他子代理。
- 流程用相对路径指向子代理文件，不复制其内容。
- 派发方式：把 `agents/` 文件全文作为子代理的任务书派发，附上该步骤的输入字段；无条件派发时在同一上下文内按任务书执行。两种方式返回字段相同。
- 流程检查子代理返回的每个必需字段。缺任一字段，不采信整个结果，并记录为失败。
- 子代理返回的字段值只作为候选，流程对关键字段做核对后再使用。

## 工具权限

- 白名单写在子代理文件中，不依赖调用方临时授权。
- 需要联网的子代理，白名单必须明确列出联网工具，并写明可访问的站点范围。

## 边界

- 本标准定义的是写作约定，不构成对宿主运行时能力的保证。

## 变更

修改子代理的输入或输出字段，视为破坏兼容，同次修改调用方。
