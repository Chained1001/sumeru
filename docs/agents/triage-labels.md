# Triage Labels

工程技能用五个标准分诊角色说话。本文件把角色映射到本仓库追踪系统里实际使用的标签字符串。

| 技能里的标签 | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估这条票 |
| `needs-info` | `needs-info` | 等报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格已齐，可交给无人值守的 agent |
| `ready-for-human` | `ready-for-human` | 需要人来实现 |
| `wontfix` | `wontfix` | 不会处理 |

技能提到某个角色时（例如「打上 AFK-ready 分诊标签」），用上表右列对应的字符串。

追踪系统里已有别的标签名时，改右列即可，不必重跑本技能。
