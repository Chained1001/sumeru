# 写作方法采集差异页

所属：采集员，与 `采集员通用.md` 配套，冲突时以本页为准。

## 范围

| 类型编号 | 文本 | S-07 或 S-08；素材不属写作方法时给改道建议 |

本大类含写作技巧、金句语料两类型。

## 特有输出槽

- 出处（对象、时间、来源，尽力补）：技巧卡与语料卡逐项必填。

## 类型特有要点

- 写作技巧卡必须写底层意图、正例与反例：**正例要给到能照着写的一句或一小段**（例文由自己写，不搬原文），只说「应该怎么做」等于没给；反例中原文明说的标〔原文〕，据素材推断重构的标〔推断〕，不混写。
- 金句语料卡必须保留原句与可仿写句式骨架；情绪词表细分按对照行收，不拆散。

## 特有停止条件

- 当素材是网络流行语时，停止并交回调用方改走 S-10（时效素材），标明未完成项。
