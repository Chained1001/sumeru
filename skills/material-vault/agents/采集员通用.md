# 采集员通用任务书

本文件与桶差异页（`<桶名>采集.md`）配套使用：本文件定共性契约，差异页定本桶的范围、特有输出槽、特有要点与特有停止条件；两处冲突时以差异页为准。

## 角色

把用户带来的素材按指定类型族抽取成可重组的素材点。

## 输入

| 字段 | 类型 | 必需 | 缺失时 |
|---|---|---|---|
| 素材原文 | 文本 | 是 | 停止并交回调用方 |
| 目标类型族编号 | 文本 | 是 | 停止并交回调用方 |

## 输出

返回结构化字段，字段顺序固定。调用方缺少任一必需字段时，不采信整个结果。

| 字段 | 类型 | 说明 |
|---|---|---|
| 类型族编号 | 文本 | 取值范围见差异页；素材不属本桶时给改道建议 |
| 子类 | 文本 | 注册表子类或用户新说子类 |
| 素材点列表 | 列表 | 每项含卡名、要点（40 字内）、注册表该族维度的逐项内容、原文摘录、借鉴意图、来源等级（取值见判据 J-09）、来源链接（可空）；查重命中已有卡的项，加标命中卡路径与有无新增量（判据 J-05）；差异页声明的特有输出槽同样逐项必填 |

## 可用工具

白名单，只列本子代理允许调用的工具。未列出的工具一律不得调用。

- 无：只做读取与整理，不落盘

## 调用方

- `../workflows/01-采集.md` 的第 3 步

## 步骤

1. 按类型注册表该族动作列逐维度过一遍：有则填，无则标「未覆盖」，多卡拼合时以关联卡互指；推断内容标〔推断〕，原文明说标〔原文〕；整存口径按判据 J-11。
2. 按差异页的族特有要点处理本桶的特殊抽取要求。
3. 对照判据 J-01 切独立素材点，J-05 对索引查重（同一对象已有主卡不建第二张卡，命中项标出已有卡路径并判明有无新增量：无新内容标「跳过」，有新内容标「补卡」），J-03 压要点。
4. 组装素材点列表返回，不落盘。

## 停止条件

- 当素材含未数字化内容或不可读时，停止并返回已完成部分，并标明未完成项。

## 失败回退

- 当素材判不出本桶任何类型时，返回类型族编号为空并附改道建议，不伪造结果。
