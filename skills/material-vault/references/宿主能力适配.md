# 宿主能力适配

## 适用范围

首次触发技能、切换宿主或工具失败时读取。只检查本次操作需要的能力，不要求用户先配置所有通道。技能使用开放的 SKILL.md 结构；宿主名称不等于权限或能力保证。

## 能力与执行方式

| 能力 | 判定依据 | 缺少时 |
|---|---|---|
| 文件读取与写入 | 当前会话确实能读写用户选定的库目录 | 只给对话内草稿，不声称已建库、已入库或已更新索引；说明缺少文件权限 |
| Node.js 执行 | 写库前检查 `node --version`，版本要求见技能随附脚本的运行约束：Node.js 24 及以上 | 停止脚本写库并说明版本或执行能力不足；不自动安装运行时，不用手写索引代替库接口 |
| 搜索 | 当前会话有可执行的关键词检索工具 | 仍可沿用户提供或已知的 URL 取证，说明未做关键词发现，不宣称搜索覆盖完整 |
| 页面读取 | 能读到目标正文、数据、字幕或评论本身 | 可用宿主浏览器或已配置的可选通道补取；仍拿不到时按 J-27 留白，不拿标题摘要代替正文 |
| 浏览器 | 宿主提供且允许使用浏览器，能够读取渲染后的目标内容 | 不要求固定浏览器品牌或启动命令；缺少时保留已拿到的资料与未覆盖面 |
| 子代理派工 | 宿主提供派工能力，且本次子代理确实拥有任务所需工具 | 无子代理时由主线程按相同任务书执行，不以缺少派工为由拒绝采集或调研 |
| 图片识读、音频转写 | 能返回实际识读或转写内容 | 按 01 采集说明限制，请用户提供文字，不猜内容 |

所有模式都要遵守宿主的实际权限。任务书是行为约定，不会给子代理新增宿主未授予的工具。

### 派工与主线程回退

1. 有子代理且工具可用时，交付任务书、类型注册表对应行、输入素材或主题及必要参考；不能只给一个子代理读不到的本地路径。
2. 无子代理时，主线程读取同一任务书，执行相同步骤、生成相同返回字段，并在继续落卡前核对字段。主线程回退不减少来源核验与查重要求。
3. 主线程有网、子代理无网时，由主线程完成取材，或把已核验材料交给采集员；不要反复派发同样无网的子代理。过程记录注明本次执行方式及未覆盖面。
4. 子代理只返回结果，不调用其他子代理、不修改库。落卡、索引与查重命令仍由调用方统一执行。
5. 主线程执行调研任务时也先记录未覆盖面，再由入口统一向用户询问缺失材料；不要把任务书写成循环追问。

## 联网通道的选择

先使用宿主原生搜索与读取工具；目标内容需要渲染时使用已可用的浏览器。已有且能用的 Agent-Reach、MCP 连接器或平台读取工具可补缺口，不是强制依赖。按宿主提供的名称映射能力，不把任何工具品牌当成唯一白名单。

例如 Claude Code 可能提供 WebSearch／WebFetch，Codex 可能提供联网工具或连接器，其他宿主可能提供 MCP 或浏览器；这些只是名称示例，不保证每个会话都有同等能力。联网工具只用于公开、只读的搜索和取证。

### Agent-Reach 可选通道

参考项目：[Agent-Reach](https://github.com/Panniantong/Agent-Reach)。Sumeru 不内置其程序，也不自动安装依赖、添加渠道、登录、更新或更改宿主配置。

- 用户已经安装并允许使用时，先查看其当前技能说明、帮助或 `agent-reach channels`，再按可用动作调用；不把当前版本的命令或渠道数写死。
- 搜索结果、正文、评论、字幕分别验证是否真正拿到。来源等级依据原始发布方与独立性判断，连接器返回成功不等于内容已经证实。
- 登录、Cookie、密钥由用户自行管理，不写进素材卡、调研记录或任务书。
- 遇到需要登录、验证码、风控或限流时停止该通道，说明哪些结果已拿到、哪些缺失；不换账号或后端绕过限制。不把某台机器的失败宣称为整个网站永久不可用。
- 完全无联网能力时只停止新增联网调研；已有素材的采集、本地检索与管理仍按可用本地能力执行。

## 脚本路径与用户工作目录

流程中的 `node scripts/vault.mjs` 相对于本技能目录。执行时先定位当前技能文件所在目录，把脚本解析为绝对路径并加引号，例如 `node "<技能绝对目录>/scripts/vault.mjs" check --vault "<用户库绝对目录>"`。不要为找脚本而改变用户工作目录，避免把默认素材库或引用包放进技能安装目录。

中文路径与空格路径都须按宿主 shell 正确引用；素材库内部仍保存相对路径。不要把某台机器的安装目录写进卡片。

旧卡中的「来源：境外」属于来源文本，可继续读取，无需迁移或改写；本轮不新增卡格式必填字段。

## 支持状态与验证

能读取 SKILL.md 只代表能加载指令。完整本地闭环还需要文件权限与 Node，联网调研另需实际联网能力，子代理是可选的执行优化。

本仓库的静态契约、模拟能力分支及 Codex 自测，不能证明 Claude Code、Cursor、Gemini CLI 等宿主已实测通过。发布说明逐宿主标注实际测试状态；用 `evals/cases/` 的兼容旅程核验触发、建库、采集、补卡、检索、私有导出及无网回退。
