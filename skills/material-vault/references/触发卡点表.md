# 触发卡点表

## 这份表干什么用

它不是分类清单，是**缺口清单**。回答一个问题：**写书项目带着一个卡点来，库里有没有料能接住它。**

```
卡点（用户的原话）  →  该查的类型  →  库里现有几张
     人工维护             人工维护        脚本算
```

第三列**由脚本按类型数卡得出，不手填**。手填必然与库漂移，而这张表一旦漂移，缺口就是假的。

## 三类条目，验法不同

- **A 类｜文本可判**：判据必须落到**可数或可指认**的对象上。「转场几处、各用什么承接」可判，「转场生不生硬」不可判。
- **C 类｜只能靠自述**：主语是「作者」而不是「文本」。写得顺的书和卡着写完的书，成稿可以长得一模一样。只能靠创作谈、大纲、废稿、后台数据。**这类不放进验证列**——它们永远无法被证伪，放进来会默认成立，把整张表的置信度抬虚。
- **不适用**：某本书里没有对应场景（无打斗、无感情线），记「不适用」，**不许记「没出现」**。把「这本书没写打斗」当成「作者没犯打斗的错」，是这张表最容易出的假阳性。

## 载体差异：连载与完整作品不是一回事

同一条卡点在两种载体上要求不同，判断前先看载体：

| 差异 | 日更连载 | 完整作品 |
|---|---|---|
| 章长 | 2000–3000 字 | 1–1.25 万字 |
| 章末 | 通常要钩子 | 情绪落地即可——`《长安的荔枝》`3 个章末零悬念、零反转 |
| 驱动力 | 更新驱动，卖「下一章」 | 倒计时／目标驱动，卖「这一趟能不能成」 |
| 结构压力 | 每章要能独立拉人 | 整体闭合即可 |

**所以 #21「章末没钩子」只对连载成立**，对完整作品照抄会误判。这一条是《长安的荔枝》逼出来的。

## 两条易被写偏的口径

**#24 不是「不写形容词」。** 大奉给的是「身体打底＋一词定性」——胃酸翻涌、脊背发凉、头皮一炸，然后补一句「他怕了！」。若按「完全不写形容词」去判，大奉会被误判成不合格。**口径是「先身体、后定性」。**

**#25 有两根挂钉：实物与时间。** 大奉的卷宗→宣纸→碎银是实物，两天／五天／日落前是时间；十日终焉的座钟与铜钟也是时间。写成「挂实物」会漏掉一半。

## 这张表怎么用

1. **写书项目带着卡点来** → 查本表找到该去的类型 → 用 `find` 取卡。
2. **维护者判断该采什么** → 看「样本证据」列，某条卡点对应类型里一张卡都没有，就是缺口。
3. **本表不进检索路径**：它是路由与缺口账，`find` 不读它。改动本表不影响库里任何卡。

## 来源

研究样本：`《诡秘之主》`、`《大奉打更人》`、`《十日终焉》`、`《绍宋》`（各取第 1-3、20-21 章）、`《长安的荔枝》`（第 1-3 章，全书仅 6 章）。原文本地存放于项目外的语料目录，按「原文不进仓库」纪律，本仓库只留结构描述与不超过 120 字的摘录。

取样理由：开篇 1-3 章测开局；中段 20-21 章**必须连续**，否则看不到「章末钩子→下章承接」。五本覆盖五个赛道：西幻、无限流悬疑、历史穿越、历史短篇（唯一非连载，用来对照载体差异）、穿越＋探案。

## 已知未校准项

`#4 打斗`、`#6 反派`、`#7 感情线`、`#19 支线` 四个条目**在这五个样本里找不到对应场景**。它们不是被证伪，是**没有被检验过**——这四条要等采集到有打斗、有成建制反派、有感情线的样本来再说。把它们记成「没出现」就是把缺样本当成缺问题。
