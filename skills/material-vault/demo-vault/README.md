# 示范库

这是别人的素材库，随技能一起分发，**只作学习用**。

你的库请自己建——入口会问你放在哪，默认 `./素材库/`。不要往这里加东西：它是分发内容，下次更新会被覆盖，你写进去的卡会不见。

## 这里有什么

十一张卡，覆盖十个类型族。**只有 S-01 开书点子这一族故意不给卡**——那一族的卡默认标「私有」，永不外流。

其余十族各有一张，其中 S-07 写作技巧有两张。**十一张里只有 S-09 作品切片那张有真出处**：切片必须能指出引自哪部作品、哪一页，与另外十张「归纳示例」不是一回事。这个区别本身就是要教的——见 `../workflows/01-采集.md` 第 0 步。

| 桶 | 类型族 | 这张示范的是 |
|---|---|---|
| 故事零件 | S-02 人物设定 | 怎么把「表层傻乐、里层认死理」写成五个维度，而不只是写一句印象 |
| 故事零件 | S-03 剧情桥段 | 怎么把一个开局套路拆成冲突结构、转折点、移植条件与失败变体 |

## 看清四件事

1. **每张卡都是三节**：基本信息、类型维度、正文。类型维度那几行的行名由类型注册表决定，不同族不一样。
2. **「要点」不超过 40 字**，「原文摘录或事实要点」不超过 120 字。写长了索引就装不下，检索时也看不出重点。
3. **示范卡标的是「线索」等级**：它们多是归纳而来，不是某一作品的原文。真采素材时来源等级要按实际填。
4. **「出自作品」这一行在本库里全空着，这不是漏填**：十张示范卡都是归纳出来的原创示例，不属于某一部具体作品，按字段定义就该留空。只有收的是某部作品里的料时才写（比如统一写「幻界战线」），写完之后能用 `find --from-work 幻界战线` 一次取回那部作品跨人设、世界设定、剧情桥段各族的全部卡——同一部作品的料散在不同族里，靠这一行归拢。

另：**「对象标识」「已用在」「补充记录」三行各有一张卡做了示范**（分别见 S-06 冷硬人名、S-11 反派狂笑、S-11 反派狂笑）。这三个字段都可不填，但填了才用得上——「对象标识」判重、「已用在」防同一个梗用两遍、「补充记录」留同一对象后来补的料。


想照着这些卡采一条自己的？把素材贴给入口，说清要收哪一类就行。
