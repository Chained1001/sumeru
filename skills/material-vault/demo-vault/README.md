# 示范库

这是别人的素材库，随技能一起分发，**只作学习用**。

你的库请自己建——入口会问你放在哪，默认 `./素材库/`。不要往这里加东西：它是分发内容，下次更新会被覆盖，你写进去的卡会不见。

## 这里有什么

十张卡，覆盖十个类型族（开书点子族除外，那一族的卡永不外流）：

| 桶 | 类型族 | 这张示范的是 |
|---|---|---|
| 故事零件 | S-02 人物设定 | 怎么把「表层傻乐、里层认死理」写成五个维度，而不只是写一句印象 |
| 故事零件 | S-03 剧情桥段 | 怎么把一个开局套路拆成冲突结构、转折点、移植条件与失败变体 |
| 故事零件 | S-04 世界设定 | 怎么让设定的代价看得见，以及漏洞在哪 |
| 故事零件 | S-05 意象氛围 | 怎么把一个画面写成可复用的意象单位，含感官词 |
| 故事零件 | S-06 起名灵感 | 怎么把起名拆成可拼装的部件，而不是攒一堆名字 |
| 写作方法 | S-07 写作技巧 | 怎么把一种写法写成可执行的步骤，并附反例 |
| 写作方法 | S-08 金句语料 | 怎么不抄原句、只留句式骨架 |
| 作品案例 | S-09 作品切片 | 怎么复述一段结构而不整段拷贝原文 |
| 现实避坑 | S-10 现实见闻 | 怎么把一条常识写成能避免写错的事实要点，并标清史料层次 |
| 现实避坑 | S-11 反面教材 | 怎么把雷点写成「为何踩雷」加替代写法 |

## 看清三件事

1. **每张卡都是三节**：基本信息、类型维度、正文。类型维度那几行的行名由类型注册表决定，不同族不一样。
2. **「要点」不超过 40 字**，「原文摘录或事实要点」不超过 120 字。写长了索引就装不下，检索时也看不出重点。
3. **示范卡标的是「线索」等级**：它们多是归纳而来，不是某一作品的原文。真采素材时来源等级要按实际填。

想照着这些卡采一条自己的？把素材贴给入口，说清要收哪一类就行。
